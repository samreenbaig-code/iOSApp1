# iOSApp1 📱  
**Tim Hortons Coffee Run App**

## 📖 Project Overview
This is a SwiftUI-based iOS app created as part of my Mobile iOS assignment.  
The app simulates a **Tim Hortons coffee run**, allowing users to enter their order, save it, and view past orders.

## ✨ Features
- 📝 **Order Form**  
  - Enter customer name  
  - Select drink and food from a picker  
  - Choose a pickup time  

- ✅ **Submit Order**  
  - Saves the order using the ViewModel  

- 📋 **Saved Orders**  
  - Displays a history of past orders with name, menu item, drink, and pickup time  

- 🎨 **UI Design**  
  - SwiftUI components (Form, Section, Picker, DatePicker)  
  - Custom background colors and header image  

## 🛠️ Tech Stack
- **Language:** Swift  
- **Framework:** SwiftUI  
- **Architecture:** MVVM (Model–View–ViewModel)  
- **Platform:** iOS
